# The Cowork Setup Journey

Five steps to go from "I have access" to "Cowork is my second brain." This is the order I would recommend if you were starting today. Not the messy way I arrived at it; the order I wish I had followed.

Each step is a separate page. Work top to bottom. Skipping ahead causes rework.

**Before you start:** Read [The Cowork Folder in OneDrive](../_Resources/cowork-folder-structure.md). It explains the `/Documents/Cowork/` layout (`copilot-instructions.md`, `skills/`, `sessions/`) that several journey steps depend on.

## The Steps

1. [**Personalize Copilot**](01-personalize-copilot.md) - Set up Microsoft 365 Copilot Custom Instructions. Cowork inherits this. Foundation for everything else.
2. [**Clean Your OneDrive**](02-clean-onedrive.md) - Cowork pulls signal from OneDrive. Clean input determines output quality. Use Cowork itself to do the cleanup.
3. [**Reorganize Your Email**](03-reorganize-email.md) - Triage inbox, set up daily briefing, build sustainable rules.
4. [**Build Your First Custom Skills**](04-build-custom-skills.md) - Anything you do more than three times a month is a SKILL.md candidate.
5. [**Build the Thinking Layer**](05-thinking-layer.md) - The `_Compass/` files: how you think, not just what you do. The highest-leverage step, and the hardest to do well.

## Why This Order

- Steps 1 and 5 are about Cowork's mind: what it knows about you, how it thinks. The bookends.
- Steps 2 and 3 are about the substrate Cowork operates on: OneDrive and email. Clean substrate, clean output.
- Step 4 sits in the middle because skills only become useful once the substrate is clean and Cowork knows enough about you to write decent first drafts.

Build the foundation before adding the leverage layers. Otherwise the leverage compounds the wrong thing.
