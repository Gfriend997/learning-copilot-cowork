# Playbooks

Structured guides for specific, repeatable project types.

Each playbook walks you through a project from cold start to completion, with the assumption that you have not done this before.

## Status

**Currently empty.** This is a placeholder folder. First playbook lands once the journey in the parent repo has been battle-tested by a few readers and a specific use case (most likely Support Scaling) has run end-to-end with real data. Watch the [CHANGELOG](../CHANGELOG.md) for additions.

- **Venture Launch** - Configuring a new business entity with proper context fencing
- **Community Management** - Using Cowork for community engagement workflows

## Playbook Format (when they land)

Every playbook will follow this structure:

1. **Cold Start** - What you need before you begin
2. **Setup** - Step-by-step configuration
3. **Verification** - How to confirm it is working
4. **Iteration** - Common adjustments after the first run
